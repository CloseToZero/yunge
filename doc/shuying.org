#+title: 数影（Shuying）

Shuying renders Org LaTeX as cached SVG previews while keeping the source
editable. Yunge enables it in Org buffers. To use the rendering library in
another mode or implement a backend, see [[file:shuying-development.org][Shuying development]].

* Start previewing

Open an Org file containing =\(x^2+y^2=z^2\)=.  In Yunge,
=shuying-org-mode= starts with =org-mode=.  After a short idle pause, formulas
visible in any window showing the buffer receive previews.  Move point into
a formula to reveal its source; edit it and leave to request a fresh image.
Opening a file does not compile every off-screen formula.

To enable the Org integration outside Yunge, put Shuying on =load-path= and
add:

#+begin_src emacs-lisp
(require 'shuying-org)
(add-hook 'org-mode-hook #'shuying-org-mode)
#+end_src

Yunge's default preview uses =xelatex= and =dvisvgm=.  Emacs must find both
on =exec-path=.  The TeX installation needs =preview.sty= and the packages
used by the Org export preamble.  Yunge adds =amssymb= and =ctex= for XeLaTeX,
so its Unicode and Chinese setup also needs the relevant math, font, and CJK
files.

| Package or group                        | Files to check                                          | Use                                   |
|-----------------------------------------+---------------------------------------------------------+---------------------------------------|
| =preview=                               | =preview.sty=                                           | Isolate formulas and report geometry. |
| =amsmath=, =amsfonts=                   | =amsmath.sty=, =amssymb.sty=                            | Common Org math and symbols.          |
| =fontspec=, =xecjk=, =ctex=, =zhnumber= | =fontspec.sty=, =xeCJK.sty=, =ctex.sty=, =zhnumber.sty= | Yunge's XeLaTeX/CJK preamble.         |
| =mylatexformat=                         | =mylatexformat.ltx=                                     | Optional preamble precompilation.     |

Check the commands and representative files from the same environment that
starts Emacs:

#+begin_src shell
xelatex --version
dvisvgm --version
kpsewhich preview.sty
kpsewhich ctex.sty
#+end_src

=kpsewhich= helps diagnose missing packages and is used by Windows setup;
rendering itself invokes the selected TeX engine and =dvisvgm=.  A different
Org compiler or custom =#+LATEX_HEADER:= may require other files.

** Install or repair the toolchain

On Windows, =M-x shuying-setup= asks before running the bundled setup.  If
MiKTeX is absent, it can download and install per-user Basic MiKTeX; it
refuses to install a second distribution when another LaTeX command is
present.  It checks the published installer SHA-256, rejects an invalid
Authenticode signature, installs its package baseline, and verifies programs
and TeX files.  Setup is explicit: opening a buffer or requesting a preview
does not install a TeX distribution.  Setup configures MiKTeX to install
missing packages without a prompt.  A first preview with a new preamble may
use that installer during its preamble check; ordinary render batches do not.
Read =*Shuying setup*= for progress or errors.  Setup can be rerun after failure:
it reuses installed packages and does not roll them back.  The command
currently supports Windows only.

On macOS and GNU/Linux, install a TeX distribution with your system's normal
installation method, then check the commands and files above.  The official
[[https://tug.org/mactex/][MacTeX]] and [[https://tug.org/texlive/acquire.html][TeX Live]]
pages describe distribution choices; [[https://miktex.org/download][MiKTeX's download page]] covers Windows.
A smaller distribution may need additional packages for your document's
preamble.  Restart Emacs or update its =exec-path= if manual installation
changes the executable search path.

* Edit and control previews

Entering a formula reveals its text; leaving it displays the image or starts
a render if it changed.  All windows showing the same Org buffer share its
previews: entering a formula in the selected window reveals its source in
every window.  In View mode, the preview at point remains visible.

Scrolling, resizing, and saving recheck visible formulas.  Cached images do
not need another TeX run.  Empty formulas and renders without visible geometry
remain source text.

Inline images use measured height and depth to follow the text baseline.
Their height is expressed in =em=, so buffer-local text scaling resizes a
cached image without rerunning TeX.

Standalone block math is tightly cropped and centered in the window text
area by default.  A block sharing its physical line with other text stays
at its source column.  SVG colors follow the live display face, so a theme
change does not require a new SVG merely to recolor it.

In Yunge, these keys are available in Evil Normal state in an Org buffer.
The =M-x= commands work without Evil.

| Key       | Command                      | Effect                                |
|-----------+------------------------------+---------------------------------------|
| =SPC m p= | =shuying-org-preview=        | Preview a region, formula, or section. |
| =SPC m P= | =shuying-org-preview-buffer= | Preview every formula in this buffer. |

=shuying-org-preview= chooses the active region first, the formula at point
next, and otherwise the current Org section.  Prefix arguments change it:

| Prefix        | Effect                                           |
|---------------+--------------------------------------------------|
| =C-u=         | Clear previews in the region or current section. |
| =C-u C-u=     | Preview the whole buffer.                        |
| =C-u C-u C-u= | Clear previews throughout the buffer.            |

A section means the current heading's own text, not its descendants.
=M-x shuying-org-clear-buffer= also removes every displayed preview.  Clearing
previews does not disable automatic previewing: visible formulas may reappear.
Toggle =M-x shuying-org-mode= off to stop the Org integration and clear its
previews.  Yunge remaps Org's =org-latex-preview= to =shuying-org-preview=.

* Configure rendering

The Org adapter uses Org's LaTeX export preamble and compiler.  Yunge defaults
=org-latex-compiler= to =xelatex= and adds =ctex= for XeLaTeX.  A file-local
=#+LATEX_COMPILER:= changes both export and previews.  Set
=shuying-latex-engine-command= to override only previews with a command
prefix such as =("xelatex" "-no-pdf")=.  The adapter also maps =latex=,
=pdflatex=, and =lualatex= to DVI-producing commands when Org selects them.

| Option                              | Default        | Use                                                                        |
|-------------------------------------+----------------+----------------------------------------------------------------------------|
| =shuying-org-block-math-alignment=  | =center=       | Set =source= to keep block math at its source column.                      |
| =shuying-org-visible-preview-delay= | =0.15= seconds | Delay viewport discovery until scrolling settles.                          |
| =shuying-max-concurrent-batches=    | =4=            | Limit concurrently running render batches.                                |
| =shuying-latex-converter-command=   | =("dvisvgm")=  | Override the SVG converter command prefix.                                 |
| =shuying-latex-precompile-preamble= | =t=            | Reuse precompiled formats when available; otherwise use the full preamble. |
| =org-format-latex-options= =:scale= | Org's value    | Change the rendered formula size and cache key.                            |

Use Emacs text scaling when you only need a temporary per-buffer size change.

Shuying reuses a cached image when its source and rendering settings match.
Cached images can be displayed even while TeX is unavailable.  Numbered
environments follow their order in the Org buffer; changing an earlier
equation can refresh later numbers.

=shuying-state-directory= defaults to =var/shuying/= under
=user-emacs-directory=.  Set it before loading Shuying to relocate defaults
for cache, render work, formats, and Windows setup files.  Explicit
=shuying-cache-directory=, =shuying-work-directory=, and
=shuying-latex-format-directory= values take precedence.  Yunge supplies
its own runtime root unless one was already configured.

=M-x shuying-clear-cache= deletes cached images and their metadata.  It refuses
to run while rendering is pending and leaves precompiled formats, render
work, and log buffers alone.  New previews recreate deleted artifacts.

* Diagnose a missing preview

Run =M-x shuying-org-preview= on the formula to surface errors that automatic
viewport previewing leaves quiet when a tool is missing.  Check that Emacs
can find the engine and =dvisvgm=, then use =kpsewhich= to locate a missing
=.sty= file.  Custom Org preambles can add dependencies beyond the table.
The error message names the relevant log buffer: =*Shuying LaTeX*= for
rendering, =*Shuying LaTeX warm-up*= for package preparation, or
=*Shuying LaTeX precompile*= for preamble compilation.  Windows installation
uses =*Shuying setup*=.  A failed page is not published as a partial preview,
and its source remains visible.

If a formula stays as source without an error, check that it contains
visible math and that point has left it.  After changing compiler, preamble,
or appearance settings, save the buffer or request a preview to recheck
visible formulas.  A cached artifact is reused only when its rendering
inputs match.
