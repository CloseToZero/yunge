#+title: 方寸（fangcun）

Each 一隅（yiyu） is an independent Org note root.  Fangcun indexes ID-based
nodes from multiple yiyu roots in a local SQLite database.  Configure each
yiyu with an identifier, display name, and root directory:

#+begin_src emacs-lisp
(setq fangcun-yiyus
      '((personal :name "Personal" :root "~/notes/personal")
        (work :name "Work" :root "~/notes/work")))
#+end_src

=M-x fangcun-file-node-create= opens a new unsaved Org file with a file-level
ID.  It uses the current file's yiyu and directory when possible, otherwise it
selects a configured yiyu.  An optional title is used verbatim as the suggested
file name, which is always shown for confirmation.

The file name is checked for characters and reserved names that cannot be shared
across the supported platforms.  Invalid input remains in the prompt for
editing; Fangcun does not rewrite it.  The name must end with =.org= and must
not already exist in the selected directory.

=M-x fangcun-db-sync= rebuilds the database from all =.org= files below the
configured yiyu roots.  A file-level =ID= creates a file node.  A heading =ID=
creates a heading node.  File nodes use =#+title= when present and otherwise
use their relative file name without the extension.  A heading without text
uses its ID as its display title.  The synchronization also indexes =id:=
links owned by the nearest enclosing node.

After a full sync, =M-x fangcun-db-update-file= replaces the indexed nodes and
links for the current saved Org file without rebuilding the other yiyu files.
Saving a configured yiyu file performs the same update silently.  Set
=fangcun-db-update-on-save= to =nil= to disable automatic updates.

=M-x fangcun-node-find= completes over the indexed nodes.  Each candidate
shows its owning yiyu and relative file.  Selecting one opens its file and
moves to the matching Org ID.

=M-x fangcun-node-insert= uses the same completion to insert an =id:= link at
point.  The selected node's title becomes the link description.

ID links may include an Org search suffix, such as
=id:NODE-ID::*Heading= or =id:NODE-ID::target=.  The suffix selects a location
inside the target node, while Fangcun attributes the backlink to the node ID.

Following an ordinary Org =id:= link resolves indexed Fangcun nodes through
the Fangcun database.  IDs not stored by Fangcun continue through Org's normal
lookup.

=M-x fangcun-backlink-find= completes over nodes linking to the node at point.
Each source node appears once.  Selecting one opens its first indexed link to
the current node.

=M-x fangcun-backlinks= opens a read-only buffer containing every indexed link
to the node at point.  Occurrences are grouped by their source node and show the
source line as a preview.  =RET= visits the link, =gr= refreshes the buffer, and
=q= closes its window.

The note map provides the frequent Fangcun commands under the global leader:

- =SPC n n= creates a file node.
- =SPC n f= finds a node.
- =SPC n i= inserts a node link.
- =SPC n b= finds a backlink to the current node.
- =SPC n v= displays backlinks to the current node.

The database defaults to =var/fangcun/fangcun.sqlite= below
=user-emacs-directory=.
