Yunge is an Emacs configuration using Evil for modal editing.

* Start

Use Emacs 31 or newer, with Git on =PATH=. Place this checkout in your Emacs
initialization directory, or start Emacs with an explicit directory:

#+begin_src sh
emacs --init-directory /path/to/yunge
#+end_src

The first startup downloads and builds packages through Elpaca, using
=elpaca-lock.el=. It needs network access. Native tools have their own setup
requirements, described in the feature guides below.

In Evil Normal state, use ~SPC f f~ to open a file, ~SPC b b~ to switch
buffers, and ~SPC SPC~ to run a command by name. See the [[file:doc/usage.org][usage guide]].
